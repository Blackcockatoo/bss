# Project Alive

The registered companion in the consumer `/pet` route has one presentation director. It uses the Expressions catalogue, personality profile and deterministic sampler. It mounts beside the existing runtime switch, which still owns the choice of Auralia, Evolved or Geometry. Gesture commands never call the store's care or progression methods. Auralia's explicit sigil actions and its advanced tools still belong to the guardian runtime.

The director publishes a frame only while a cue plays. Auralia applies frames to its native eyes, body and wardrobe layers. Evolved maps the same frame to the movement interpreter's bounded anatomical channels and uses its existing Evolved movement priority. The Geometry wrapper modulates the outer pose and resonance of the checksum-locked sprite. Existing care reactions, critical states and evolution ceremonies gate presentation. Interruptions between compatible cues carry the previous pose through a short crossfade. Pausing affects presentation and audio while the normal care clock remains active.

Mouse, touch and pen use the existing touch nervous system. The stage keeps vertical panning enabled. Auras and gentle poses reflect gesture strength and the inherited personality. Seeded, infrequent ambient cues run while the stage is visible. Reduced-motion playback presents brief static cues.

Music interaction starts disabled. The genome rhythm uses the existing Forge audio scheduler and sends timed notes, subdivisions and downbeats to the director. A selected local file can drive estimated bass onsets using Web Audio. The source is the file or the synthesiser. No microphone permission is requested. Learned projects use their existing saved motif and retain the same local identity boundary.

A recording stores the latest take per registered pet. It contains only a form and bounded theatrical cue directives, relative times, energy, direction and duration. It omits raw pointer paths, audio, genome data and care events. Open the saved take in the Expression Studio to edit cues and export the recorded choreography on the same companion. One take can hold up to 48 cues over a 12-second recording window. Animated export uses a bounded frame plan with a sample inside every playable cue, including short musical beats.
